GhostRigger Developer Handoff Bundle

This bundle contains the locally packaged files produced during the GhostRigger research and planning cycle, plus the three reference books supplied by the user.

Included local files
- prompts/ghostrigger_dev_prompt.md
- docs/D6CAtSpB.md  (Character Builder developer-facing spec)
- docs/p3Bhgvip.html  (Full architecture / code audit)
- docs/XFFuz1p2.md  (Ultimate build guide / cross-reference document)
- spreadsheets/pVRMhxC8.xlsx  (Feature mapping and OpenKOTOR repository matrix)
- spreadsheets/xUA4mdUu.xlsx  (Prioritized implementation roadmap)
- images/contact_sheet.jpg  (Video contact sheet used during UI analysis)
- books/_OceanofPDF.com_Computer_Graphics_Development_with_OpenGL_-_Wilson_Hayes.pdf
- books/_OceanofPDF.com_3D_Mesh_Processing_and_Character_-_Ramakrishnan_Mukundan.pdf
- books/_OceanofPDF.com_Game_Engine_Architecture_4Ed_-_Jason_Gregory.pdf
