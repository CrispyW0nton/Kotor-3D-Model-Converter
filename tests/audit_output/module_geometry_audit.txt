FIXES APPLIED DURING AUDIT
----------------------------------------
1. kotor_loader.py _read_mesh():
   MDLMesh.tangent_space is a BOOLEAN FLAG (True = tangent data present),
   NOT a list of tangent vectors. The old code iterated it:
     gr.tangents = [(float(t.x), ...) for t in (mesh.tangent_space or [])]
   Fixed: gr.tangents = []  (tangents computed by exporter from normals+UVs)

2. PyKotor/Libraries/.../io_mdl.py _LightHeader.read():
   flare_radius (float) must be read FIRST at offset +0x00, BEFORE the
   3-uint32 unknown array block. Previous order placed flare_radius last
   (after all 4 flare-data arrays), causing a 4-byte misalignment in all
   subsequent fields. This made 45 light-node-containing module MDLs fail
   to parse (33 K1 + 12 K2).
   
   Root cause confirmed by:
     - Binary data inspection: offset +0x00 = 0x49371b00 = 750000.0 (float)
     - kotorblender reader.py:247: flare_radius = self.mdl.read_float() [first]
     - Wiki/MDL-MDX-File-Format.md:484: offset 0x10 = Flare Sizes offset
   
   Affected K1 models (33): m02ab_02j, m08aa_10c, m12ac_01a, m12ad_01a,
