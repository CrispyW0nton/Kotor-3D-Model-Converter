# Kotor-3D-Model-Converter

Open-source Python toolkit for modding **Star Wars: Knights of the Old Republic 1 & 2**.

---

## 📁 GhostRigger

The main project lives in **[GhostRigger-K1-K2/](GhostRigger-K1-K2/)**.

GhostRigger is a full pipeline for reading, writing, and converting KotOR's proprietary
Odyssey Engine 3D model format (MDL/MDX) — pure Python, no game installation required
for the core library.

**[→ Go to GhostRigger](GhostRigger-K1-K2/README.md)**
