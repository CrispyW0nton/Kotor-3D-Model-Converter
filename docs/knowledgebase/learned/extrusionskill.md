# Extrusion Skill

Use this skill for face extrusion, bevel, inset, edge-loop, generated mesh tools,
and any feature that creates new vertices/faces from existing topology.

## Book Grounding

- `3D Math Primer`: polygon meshes, planes, triangles, transforms, and geometric tests.
- `Mathematics for Computer Graphics`: vector normals, transforms, arbitrary-axis rotation, interpolation, and area/triangle tests.
- `3dsmax2020_ref_guide`: practical mesh diagnostics for open edges, multiple edges, T-vertices, flipped normals, missing UVs, and viewport statistics.
- `Rig it Right` and `Digital Creature Rigging`: deformation quality depends on clean edge flow, stable pivots, and prepared geometry.

## Workflow

1. Decide the operation type: region extrusion, individual face extrusion, edge extrusion, bevel, inset, shell/thickness, or bridge.
2. Capture the source selection and adjacency graph before modifying topology.
3. Compute extrusion direction deliberately: face normal, averaged vertex normal, user axis, local transform axis, world axis, or camera axis.
4. Create new vertices with stable provenance: source vertex ID, generated ID, position, normal/tangent strategy, UV strategy, and material slot inheritance.
5. Stitch side faces with consistent winding. Validate each new quad/triangle against the mesh handedness and renderer winding convention.
6. Decide what happens to UVs and weights. For GhostRigger, generated topology that belongs to a skinned mesh must either copy/interpolate weights or be marked unsupported by the tool.
7. Run topology cleanup: remove zero-area faces, merge only intentional duplicate vertices, and flag open boundaries that are not expected.

## Validation Checklist

- New faces have consistent winding and visible normals.
- No unintended holes, overlapping faces, isolated vertices, or T-vertices.
- Material slots and UV coordinates are inherited or generated by a documented rule.
- Selection state maps from source to generated topology predictably.
- Pivot/object transforms remain unchanged unless the operation explicitly edits them.
- Skinned/generated vertices have defined weight behavior.

## GhostRigger Checks

- Put reusable extrusion/topology code in a core/system/math owner, not inside a window or viewport mixin.
- Use `PLC_bench` for static visible object-tool checks unless the user names another model.
- If extrusion affects KMAX/KMAP scene data, preserve human-readable scene/project files and stable IDs.
